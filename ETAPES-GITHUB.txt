ÉTAPE 2 : Créer un Personal Access Token (1ère fois)
═══════════════════════════════════════════════════════════════

GitHub n'accepte plus les mots de passe depuis 2021.
Vous DEVEZ utiliser un Personal Access Token.

1. Ouvrir : https://github.com/settings/tokens

2. Cliquer : "Generate new token" → "Tokens (classic)"

3. Configuration :
   ┌─────────────────────────────────────────────────┐
   │ Note:        pulsai-upload                      │
   │ Expiration:  90 days (ou No expiration)         │
   │ Scopes:      ✅ repo (cocher SEULEMENT ça)      │
   └─────────────────────────────────────────────────┘

4. Cliquer : "Generate token"

5. COPIER LE TOKEN (impossible de le revoir après!)
   Format : ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

6. GARDER LE TOKEN (notepad, notes, etc.)
